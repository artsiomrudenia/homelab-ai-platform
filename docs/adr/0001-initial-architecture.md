# ADR-0001: Initial Architecture

- Date: 05/10/2026
- Status: Accepted

## Context

The project requires a practical public baseline for self-hosted AI platform operations in a homelab Kubernetes setup.

## Decision

Use a minimal FastAPI service and provide complete cloud-native delivery artifacts (Docker, manifests, Helm, CI).

## Consequences

- Easy local experimentation
- Clear path for platform module growth
